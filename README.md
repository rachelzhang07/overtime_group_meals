# overtime_group_meals
# 深夜团餐助手使用说明

深夜团餐助手是一款面向加班团队的麦当劳点餐工具。它把深夜门店查询、多人餐品搭配、优惠券领取与试算、订单确认、支付链接、账单分摊和报销辅助串联在同一个程序中。

项目只有一个 Python 文件：

```text
night_group_meal_assistant.py
```

## 一、可以做什么

- **深夜找门店**：按目标用餐时间筛选营业门店，支持跨午夜营业时间。
- **多种取餐方式**：支持到店自取、外送和得来速；外送还支持企业团餐与助餐服务。
- **智能搭配团餐**：根据人数、预算和口味生成主食、小食、饮品组合。
- **自动领取并试算优惠**：领取可用优惠券，并通过真实 `calculate-price` 接口比较候选方案。
- **确认后下单**：完整展示订单，只有输入“确认下单”才会创建真实订单。
- **返回支付链接**：显示真实接口返回的支付链接；未返回时引导前往官方订单页面。
- **生成三张账单**：提供预估账单、实付账单和分摊账单。
- **辅助报销**：提供开票入口指引和报销材料清单。
- **精确分摊**：支持多人 AA 和自定义权重，金额精确到分，分摊合计与账单总额一致。

## 二、演示模式与真实模式

| 模式 | 数据来源 | 是否需要 Token | 是否可能创建真实订单 |
| --- | --- | --- | --- |
| 演示模式 `demo` | 内置示例数据 | 不需要 | 不会 |
| 真实模式 `real` | 麦当劳真实 MCP | 需要 | 确认后会 |

演示模式中的门店、餐品、订单号和支付凭证都带有演示标识，不能当作真实消费记录或报销凭证。

## 三、先体验演示模式

### 1. 安装 Python

安装 **Python 3.10 或更高版本**。Windows 安装时请勾选 **Add Python to PATH**。

### 2. 打开命令行

在 `night_group_meal_assistant.py` 所在文件夹中打开终端。

Windows 用户可以在文件夹地址栏输入 `cmd` 并按回车。

### 3. 运行自测试

```bash
python night_group_meal_assistant.py self-test
```

看到以下结果表示内置测试通过：

```text
Ran 17 tests
OK
```

自测试只使用本地数据，不连接麦当劳服务，也不会创建真实订单。

### 4. 自动运行完整演示

```bash
python night_group_meal_assistant.py demo --yes
```

程序会演示：

1. 筛选深夜营业门店。
2. 领取演示优惠券。
3. 推荐 8 人团餐方案。
4. 创建演示订单。
5. 生成预估、实付和分摊账单。
6. 保存结果到 `night_group_meal_demo_result.json`。

当前内置示例会给出 **187 元**和 **188 元**两种方案，均满足 200 元预算。这些金额仅用于演示。

如果希望逐步选择方案和确认订单，可以去掉 `--yes`：

```bash
python night_group_meal_assistant.py demo
```

## 四、配置真实 MCP

真实模式需要你已经申请到麦当劳 MCP Token。

### 1. 安装真实模式依赖

```bash
python -m pip install "mcp>=1.10,<2.0"
```

演示模式不需要安装该依赖。

### 2. 配置 Token

选择以下一种方式。

#### 方式 A：直接修改文件

用文本编辑器打开 `night_group_meal_assistant.py`，在文件顶部找到：

```python
MCP_TOKEN = "YOUR_MCP_TOKEN"
```

将 `YOUR_MCP_TOKEN` 替换为你自己的真实 Token。

#### 方式 B：使用环境变量

Windows PowerShell：

```powershell
$env:MCD_MCP_TOKEN="你的真实Token"
```

Windows CMD：

```cmd
set MCD_MCP_TOKEN=你的真实Token
```

环境变量优先于文件内的 Token，并且只在当前终端窗口中生效。


## 五、开始真实点餐

运行：

```bash
python night_group_meal_assistant.py real
```

程序会依次引导你完成以下操作。

### 1. 填写团餐需求

- 用餐人数。
- 总预算，直接回车表示不限。
- 取餐方式：到店自取、外送或得来速。
- 口味：混合、不辣或辣。
- 预约时间，直接回车表示立即用餐。

“不辣”筛选主要依据餐品名称和标签。如有食物过敏、素食或其他严格忌口，请继续核验餐品详情，不要仅依赖名称判断。

### 2. 选择门店

- **到店自取或得来速**：输入城市和位置关键词，例如“南京市”和“科技园”。
- **外送**：选择已有收货地址；没有地址时，可按提示新增。
- **企业团餐**：按提示选择企业团餐及门店提供的助餐服务。

如果目标时间没有营业门店，可以调整位置、预约时间或取餐方式后重试。

### 3. 确认餐品和优惠

程序会查询当前可售餐品、领取可用优惠券，并对候选餐品和券组合进行真实算价。

展示的是“已试算候选中的较优方案”，不是对所有可能组合的全局最优承诺。最终金额以真实接口和订单返回为准。

### 4. 确认并创建订单

下单前请仔细核对：

- 门店和取餐方式。
- 预约时间或立即用餐。
- 餐品及数量。
- 优惠券和费用明细。
- 订单总金额。
- 外送地址、备注和助餐服务。

确认无误后，完整输入：

```text
确认下单
```

输入其他内容不会创建订单。

### 5. 获取订单与支付链接

创建成功后，程序会显示订单号、订单状态和真实接口返回的支付链接。

请注意：

- **创建订单不等于支付成功。**
- 支付链接不是支付凭证。
- 未支付前，实付账单保持“待确认”，分摊账单标记为“预估分摊”。
- 下单异常或超时后，程序不会自动重试。请先到官方订单列表核实，避免重复下单。

订单结果会保存为类似下面的 JSON 文件：

```text
night_group_meal_real_订单号.json
```

## 六、支付后生成实付与分摊账单

完成支付后，使用订单号运行：

```bash
python night_group_meal_assistant.py settle 订单号 --names 甲,乙,丙
```

例如：

```bash
python night_group_meal_assistant.py settle 1030938730000733964700499858 --names 张三,李四,王五
```

程序会查询真实订单状态，并生成实付和分摊结果，保存为：

```text
night_group_meal_settlement_订单号.json
```

如果当前订单状态无法确认已支付，程序不会生成“已实付”结论。

### 三张账单的区别

| 账单 | 含义 |
| --- | --- |
| 预估账单 | 下单前的餐品、配送费、服务费、优惠和预计应付金额 |
| 实付账单 | 支付后根据真实订单状态核验的实际金额；未支付时显示待确认 |
| 分摊账单 | 将实付或预估金额分配到每位成员，并保证分币合计一致 |

开票和报销请以麦当劳官方页面为准。建议保留订单明细、实付账单、支付凭证和分摊表。

| `python night_group_meal_assistant.py self-test` | 运行本地自测试 |
| `python night_group_meal_assistant.py demo` | 交互式演示 |
| `python night_group_meal_assistant.py demo --yes` | 自动完成演示 |

## 八、常见问题

### 提示“python 不是内部或外部命令”

重新安装 Python，并勾选 **Add Python to PATH**。也可以尝试将命令中的 `python` 换成 `py`。

### 提示缺少 MCP SDK

执行：

```bash
python -m pip install "mcp>=1.10,<2.0"
```

### 提示尚未配置 Token

检查是否已替换 `YOUR_MCP_TOKEN`，或当前终端是否设置了 `MCD_MCP_TOKEN`。

### 返回 401

Token 可能无效、过期或未正确配置。请检查 Token 和 `Authorization` 配置，不要使用演示占位符调用真实服务。

### 返回 429

说明请求受到限流。请暂停频繁操作，稍后再试，不要连续重复运行。

### 查询不到营业门店

检查城市和位置关键词，尝试调整预约时间、收货地址或取餐方式。

### 算价成功但无法下单

到店场景需要真实算价返回的取餐码，外送场景需要收货地址 ID，企业团餐还需要助餐服务码。缺少这些信息时不要强行下单，请记录错误并检查实际接口返回。

### 下单超时或结果不明确

不要立即再次运行下单。先检查麦当劳官方订单列表，确认是否已经生成订单，防止重复支付或重复下单。

### 没有返回支付链接

前往麦当劳官方订单页面查找对应订单并核实支付入口，不要使用其他来源不明的链接。

## 九、使用边界

- 实时门店、库存、餐品、优惠、价格和订单状态均以麦当劳服务返回为准。
- 优惠券只比较程序实际试算的候选组合，不承诺所有组合中的绝对最低价格。
- 食品过敏和严格忌口需要进一步核验餐品详情。
- 程序不会替你完成支付，也不会把创建订单误认为支付成功。
- 本地自测试不代表你的 Token 已完成在线联调；首次真实使用时请先核对门店和订单信息。
- 请勿在公开提交或分享的源代码中保留真实 Token。
